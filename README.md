# MIG Expert Dashboard

Base inicial pronta para GitHub Pages.

## Como publicar
1. Crie um repositório no GitHub.
2. Envie todos os arquivos desta pasta.
3. Vá em Settings > Pages.
4. Em Build and deployment, escolha Deploy from a branch.
5. Selecione a branch `main` e a pasta `/root`.
6. Aguarde a URL pública.

## Estrutura
- `index.html`: entrada principal
- `assets/css/styles.css`: estilos
- `assets/js/`: scripts do app
- `data/`: reservado para conteúdos base
- `docs/`: documentos de arquitetura

## Observação
Esta versão usa perfis locais no navegador e exportação/importação em JSON.
